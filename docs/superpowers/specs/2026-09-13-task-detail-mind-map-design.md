# 任务详情可编辑脑图设计

## 目标

在任务详情页用真实的可拖拽连线脑图替代静态领域地图卡片。脑图用于展示并编辑任务的前置知识、核心概念和进阶方向。

## 技术方案

- 使用 `@xyflow/react` 提供节点拖拽、连接、缩放、选择和删除能力。
- 脑图节点和边作为任务详情数据的一部分持久化；任务保存时与步骤、目标和资源一起写回。
- 旧任务首次打开时，由已有领域地图字段生成默认的三组节点与顺序连接边。

## 交互

- 节点显示文本，可双击编辑。
- 拖动节点更新其坐标；从节点连接点拖出可创建边。
- 工具栏提供添加节点、删除选中节点、适配视图和撤销当前未保存更改。
- 节点、连线和布局在“确认并保存”后持久化。

## 页面布局

- 顶部只保留返回、只读任务标题和可编辑完成目标；不显示任务类型、总进度或独立全局问题区。
- 返回为只含箭头图标的独立方形按钮，不显示文字。
- 顶部标题和完成目标属于页面正文滚动内容，不固定在视口。
- 左栏上部为大面积脑图画布，高度约 560px；下部为可编辑推荐资源。
- 右栏上部为可编辑“需要注意的点”；下部为完整步骤工作区。
- 左栏脑图和资源卡保持固定视觉比例；步骤工作区设为固定高度，新增步骤后仅在工作区内部滚动。
- 步骤行紧凑呈现拖拽、完成勾选、序号、可编辑名称、可编辑时长和删除；每步核心问题不在行内显示，作为脑图节点或编辑数据保留。
- 深色主题使用深灰画布、低对比网格和当前强调色连接线；浅色主题使用现有表面与边框变量。
- 移动端画布保持最小高度并支持触控平移、缩放。
- 双击脑图画布打开全屏脑图窗口，展示完整节点、连线和同一套编辑能力；关闭后保留未保存的脑图草稿。

## 验收

- 用户可拖动节点、创建连线、添加/删除节点并保存后恢复布局。
- 旧任务无脑图数据时能生成并显示默认脑图。
- 详情页步骤、资源、目标和保存操作不回归。
