# 任务详情可编辑脑图设计

## 目标

在任务详情页用真实的可拖拽连线脑图替代静态领域地图卡片。脑图用于展示并编辑任务的前置知识、核心概念和进阶方向。

## 技术方案

- 使用 `@xyflow/react` 提供节点拖拽、连接、缩放、选择和删除能力。
- 脑图节点和边作为任务详情数据的一部分持久化；任务保存时与步骤、目标和资源一起写回。
- 旧任务首次打开时，由已有领域地图字段生成默认的三组节点与顺序连接边。

## 交互

- 节点显示文本，可双击编辑。
- 拖动节点更新其坐标；从节点连接点拖出可创建边。
- 工具栏提供添加节点、删除选中节点、适配视图和撤销当前未保存更改。
- 节点、连线和布局在“确认并保存”后持久化。

## 页面布局

- 左栏上部为脑图画布，高度约 430px；下部保留可编辑推荐资源。
- 深色主题使用深灰画布、低对比网格和当前强调色连接线；浅色主题使用现有表面与边框变量。
- 移动端画布保持最小高度并支持触控平移、缩放。

## 验收

- 用户可拖动节点、创建连线、添加/删除节点并保存后恢复布局。
- 旧任务无脑图数据时能生成并显示默认脑图。
- 详情页步骤、资源、目标和保存操作不回归。
