# 浅色主题一致性优化设计

## 目标

将浅色主题统一为暖白表面、冷灰背景、深灰文字、低饱和边框与绿色强调色，修复导航、任务清单、待办编辑、AI 审核、功能页和设置页仍残留的深色样式或低对比度问题。

## 设计边界

- 深色主题的既有外观和行为不变。
- 不改变任务、待办、提醒、AI 审核或设置的数据与交互逻辑。
- 样式调整以现有 `html[data-theme="light"]` 覆盖层和共享 CSS 自定义属性为主，避免把浅色值散落到组件中。

## 视觉令牌

- 页面背景：带极弱网格的冷灰；卡片、导航与弹窗使用暖白实体表面。
- 文字：主文字为深炭灰；说明、占位符与已完成状态使用足够可读的中灰。
- 控件：输入、搜索、选择、文件选择和时间选择使用浅灰填充、灰色边框、深色输入文字；焦点使用绿色边框与克制光晕。
- 操作：主操作为绿色实底深色文字；次级操作为白色或浅灰表面，悬停只使用轻微绿色染色。
- 结构：卡片与分隔线使用中性灰边框，避免纯白区域与背景融成一片。

## 组件范围

### 导航与任务清单

- 导航未选中、悬停和选中状态均保持深色文字及明显层级。
- 任务统计、标题、搜索框、筛选/分隔区域、任务卡正文与步骤信息均使用统一的浅色文字与表面令牌。

### 待办、提醒与弹窗

- 编辑待办、添加待办、AI 审核待办与提醒时间字段不再继承深色背景。
- 弹窗保持白色主体、深色文字、柔和边框和深灰遮罩；输入控件的状态与页面内表单一致。

### 功能页与设置页

- 功能页头部保持透明，不出现突兀白色标题块。
- 设置表单、下拉框、数值框、导入文件控件及功能操作项统一表面、边框、文字和焦点样式。

## 验收标准

- 浅色主题下，截图所示的导航、搜索、任务卡、所有待办输入、提醒时间、AI 审核输入和设置表单均无黑色输入框、白色文字或低对比度文字。
- 控件与其容器有清晰但不过重的边界；绿色仅承担强调、状态和主要操作。
- 所有已覆盖页面在深色主题下外观不发生变化。
- 自动化测试与类型检查通过，并增加或调整样式断言以覆盖浅色主题关键控件。
