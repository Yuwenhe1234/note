# 浏览器通知待办提醒设计

## 目标

让网站在用户授权后通过浏览器系统通知提醒待办；用户切换到其他网页时仍可看到通知。网页左上角卡片继续作为当前页面的补充。

## 开关与授权

- 设置中心保留“浏览器通知”开关并将启用状态保存到本地设置。
- 首次开启且权限为 `default` 时请求一次 `Notification.requestPermission()`；授权成功后不再重复请求。
- 权限为 `granted` 时开启开关立即生效；关闭开关只停止应用发送通知，不撤销浏览器权限。
- 权限为 `denied` 或 API 不存在时，开关保持关闭并显示明确恢复说明；浏览器拒绝后必须由用户在地址栏站点权限中改为“允许”，网页不能自行再次弹出授权框。

## 提醒行为

- 待办到点时，若开关启用且权限已授权，发送一次带待办内容和设定时间的系统通知。
- 当前页面仍显示左上角网页卡片；系统通知失败或不可用不阻断卡片。
- 计时、队列和 AI 陪伴未来订阅端口不变。浏览器/网页关闭、休眠时不补发。

## 验收

- 首次打开开关只请求一次授权；已授权再次开启不再请求。
- 授权后到点调用 `Notification`；未授权、拒绝或不支持时不调用但显示网页卡片。
- 拒绝状态显示浏览器站点权限恢复说明。
