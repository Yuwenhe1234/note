# 今日消息横向三行卡片交互设计

## 目标

优化“今日消息”页面的信息密度和刷新交互。刷新按钮不再横跨主内容区；消息以三行卡片轨道展示，内容增多时向右延伸并支持水平浏览。

## 页面布局

- 页面顶部保留返回入口、`DAILY SIGNALS`、“今日消息”标题和说明文案。
- 主体分为左右两列：左侧是订阅来源，右侧是消息卡片轨道。
- 左侧保留来源输入、添加、登录和删除操作。
- 刷新按钮放在来源面板下方，宽度与左侧面板一致，不占用右侧内容宽度。
- 窄屏时左右两列改为上下排列，卡片轨道仍支持水平滚动。

## 消息卡片轨道

- 消息卡片按列填充，每列固定三张，新内容继续向右增加。
- 卡片宽高统一，默认只显示 UP 主名字和视频标题。
- 标题超出卡片可视范围时限行省略，完整内容在详情中显示。
- 轨道内容超出可视宽度时允许水平滚动，同时支持触摸板、Shift + 滚轮和拖动滚动条。
- 保留可见的水平滚动提示，让用户能发现右侧还有内容。
- 新刷新到的卡片加入轨道，不改变已有消息的保留规则。

## 详情交互

- 整张“UP 主名字 + 视频标题”卡片是可点击区域，并可通过键盘聚焦后使用 Enter 或 Space 打开。
- 点击卡片后打开一个详情子方框，展示该条内容的完整摘要。
- 再次点击当前卡片关闭详情；点击其他卡片时直接切换详情内容。
- 同一时间只显示一条详情，避免多个长文本方框同时展开破坏布局。
- 详情子方框不影响消息轨道的三行排列，使用轨道下方的独立详情区域展示。

## AI 总结展示格式

详情子方框固定按以下顺序展示：

```text
UP 主：科技观察站
视频标题：AI Agent 的最新进展

一句话总结
本期介绍了 AI Agent 在任务规划、工具调用和长期记忆方面的最新进展。

核心内容

1. Agent 可以把复杂目标拆分为多个执行步骤。
2. 工具调用让 Agent 能访问网页、文件和外部服务。
3. 长期记忆仍存在信息污染和隐私风险。

重点信息

- 适合场景：资料整理、自动化办公、研究辅助
- 主要限制：执行稳定性、成本、权限安全
- 视频结论：Agent 正从聊天工具转向可持续执行任务的系统

值得关注
视频展示了一个可直接落地的工作流，并说明了当前方案的风险边界。

内容依据
根据爬取到的视频简介、字幕或正文生成。
未在原始内容中出现的信息不得补充或推测。

发布时间：2026-09-07 10:30
原视频：https://...
```

“内容依据”会根据实际成功获取的资料标明为视频字幕、语音转写、视频简介或网页正文。不得将只基于简介的摘要标记为已分析完整视频。

## 内容获取与降级

- 第一优先级：获取平台字幕或自动字幕。
- 第二优先级：没有字幕时，使用视频简介、视频页文本或网页正文。
- 预留语音转写能力；本次 UI 优化不新增视频下载和语音识别依赖。
- AI 只能根据已获取的内容生成总结，不得补充或推测未在来源中出现的事实。

## 刷新状态与错误处理

- 默认按钮文案为“刷新”，保留刷新图标。
- 刷新期间显示“刷新中…”并禁止重复点击。
- 刷新完成后保留现有的新增数量、暂无新消息和部分来源失败提示。
- 单个来源失败不阻止其他来源的新消息加入轨道。

## 数据与范围

- 继续使用现有消息、来源和三天保留机制。
- 新增 UI 选中状态，用于记录当前展开详情的消息 ID；该状态不需要持久化。
- 为后续更精确的 AI 输出预留结构化字段，但本次实现可兼容已存储的 `summary` 和 `highlights`。
- 本次不改变订阅、登录、爬取、去重和缓存的现有业务规则。

## 验收标准

- 刷新按钮位于左侧来源面板下方，不再占据右侧主内容宽度。
- 右侧消息按三行排列，超出宽度后可向左或向右滚动。
- 卡片默认只显示 UP 主和视频标题。
- 卡片可通过鼠标和键盘打开、切换或关闭单个详情子方框。
- 详情按已确认的 AI 总结顺序展示，原视频链接位于最底部。
- 刷新中不能重复提交，现有成功和失败提示保持可用。
- 所有现有页面测试通过，并新增布局、水平滚动和详情展开的交互测试。
