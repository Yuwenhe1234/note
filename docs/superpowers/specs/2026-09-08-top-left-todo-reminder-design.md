# 左上角待办提醒设计

## 目标

将今日待办的网页提醒由居中遮罩弹窗调整为浏览器左上角的轻量提醒卡片，提醒出现时不阻塞或遮罩现有页面。

## 界面与交互

- 卡片固定在视口左上角，避开页面边缘，层级高于常规内容。
- 延续现有深色背景、浅绿色描边和“REMINDER”标识，但采用紧凑尺寸与较小标题。
- 卡片显示待办内容、设定时间和“我知道了”按钮。
- 卡片不会自动消失，用户点击“我知道了”后展示队列中的下一项，或在队列为空时关闭。
- 不添加全屏背景、模糊效果或焦点锁定；页面其余区域保持可点击和可滚动。

## 架构边界

提醒调度器、提醒事件以及 AI 陪伴未来的订阅端口保持不变。本次仅替换 `App.tsx` 使用的 CSS 类表现，并更新组件测试以验证提醒不再使用全屏遮罩。

## 验收

- 到点后左上角出现提醒卡片。
- 页面仍可以在提醒出现时操作。
- 点击确认后队列规则不变。
- 不存在覆盖整个视口的提醒遮罩。
