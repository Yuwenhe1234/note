# 浅色主题组件细节修复设计

## 目标

修复浅色主题中仍被深色规则覆盖的导航、功能页、任务卡和弹窗，确保所有组件的文字、表面、输入和交互层级清晰一致。

## 覆盖规则

- 顶部主导航的活动项使用浅灰背景和深色文字；所有导航项在浅色模式保持可读。
- 仅主应用壳顶部导航使用白色表面，功能页的 `feature-window-header` 保持透明，不产生白色矩形或阴影。
- 浅色任务卡、设置卡、功能卡和空状态使用统一文字与边框令牌，完成状态保留删除线但不降低到不可读。
- 普通待办编辑、AI 审核、任务编辑中的 input、textarea、时间选择按钮和步骤时长输入均使用次级浅表面、深色文字和中性边框。
- 遮罩使用半透明深灰，弹窗白色表面与内容对比清晰；强调色仅用于操作和状态。

## 验收

- 浅色模式下导航文字、功能页标题、任务说明、空状态、输入内容和完成任务均可直接阅读。
- 不出现功能页标题白底块、黑色输入框或近白文字。
- 深色主题现有外观不被改变。
