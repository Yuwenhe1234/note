# 浅色主题视觉优化设计

## 目标

将浅色主题从高亮纯白风格调整为柔和冷灰体系，恢复清晰层级、舒适对比度和与深色主题一致的专业感。

## 色彩与层级

- 页面背景使用浅冷灰，网格降低透明度；顶部的强调色环境光保持极弱。
- 导航、设置卡片、任务卡与弹窗使用实体白色表面；次级区域使用略深的冷灰。
- 主文字使用深炭灰，辅助文字提高对比度，边框使用中性灰而非发光描边。
- 浅色主题为绿色、蓝色、橙色提供更深的强调色值，保证小字、描边和按钮可读。

## 交互

- 顶部导航阴影减轻并缩小扩散范围。
- 卡片 hover 使用轻微强调色染色、细描边和小幅位移，不使用大面积荧光。
- 输入、按钮、弹窗和登录页共享相同表面与边框变量。
- 错误、警告和中性文字继续使用语义色。

## 验收

- 页面不再呈现大面积刺眼纯白或白雾效果。
- 导航、卡片、输入框和背景之间层级清晰。
- 三种强调色在浅色主题下均有足够对比度。
- 主页面、设置、登录、功能页和弹窗视觉一致。
