# 深浅主题与全站强调色设计

## 目标

外观设置仅保留主题与强调色。主题支持深色、浅色；强调色支持绿色、蓝色、橙色，并统一作用于主站、二级页面、弹窗和登录界面。设置持久化，刷新后恢复。

## 规则

- 删除字体大小与界面密度控件，但保留旧数据兼容。
- 主题选择立即写入 `document.documentElement.dataset.theme`，页面启动和登录页渲染前从本地设置恢复。
- 所有现有绿色交互色改为 CSS 强调色变量及透明派生色，包括按钮 hover/focus 光圈、选中态、边框、滚动条、标签和品牌圆形图标。
- 错误红、警告色、灰色辅助文字和黑白正文保持语义颜色。
- 浅色主题替换页面、卡片、输入框、边框和正文颜色，保证可读对比度。

## 验收

- 外观页只显示主题和强调色。
- 切换主题或强调色后全站立即变化，刷新和重新登录后保持。
- 品牌图标、登录页、按钮 hover/focus 与各功能页不再残留写死绿色。
