# Tauri 跨应用提醒设计

## 目标

将 Windows EXE 作为常驻提醒服务：主窗口关闭后最小化到系统托盘，继续读取本地今日待办；到点后在屏幕左上角显示原生置顶提醒窗，无论用户正在浏览网页或使用其他普通应用。

## 架构

在 Tauri 原生层新增隐藏的 `desktop-reminder` 窗口和单例调度器。调度器每 30 秒读取当前本地工作区中的未完成今日待办，匹配当天未来或当前分钟的合法 `HH:mm` 提醒时间，并通过窗口事件把提醒交给该窗口的 WebView 显示。

提醒窗口始终置顶、跳过任务栏、无边框、透明且不自动聚焦；出现时位于主显示器左上角并带 24px 边距。窗口确认动作调用原生命令确认当前提醒，调度器随后显示同一分钟已排队的下一项。网页内提醒和已有桌面小组件继续工作，不依赖此窗口。

## 托盘与生命周期

- EXE 启动后创建系统托盘图标，菜单包含“打开主窗口”和“退出应用”。
- 用户关闭主窗口时取消关闭、隐藏主窗口，Tauri 进程继续运行。
- 用户从托盘选择“退出应用”时才终止进程并停止提醒。
- 设备休眠、应用未运行或提醒时间已过时不补发；恢复后等待下一次未来提醒。

## 调度规则

- 每个待办 ID 在一天内最多触发一次；重复轮询、窗口重显示和工作区刷新不得重复提醒。
- 待办被完成、删除、编辑为其他时间后，下次轮询不再触发旧值。
- 多个到点待办依照工作区数组顺序进入提醒队列，确认当前卡片后显示下一项。
- 不合法时间、无法读取工作区或没有当前工作区时跳过本轮，并在原生日志记录可诊断错误，不退出应用。

## 界面与权限

- `desktop-reminder` 使用简洁的深色左上角卡片，展示“待办提醒”、内容、设定时间和“我知道了”。
- 仅提醒窗本身可点击；窗口尺寸紧贴卡片，不创建覆盖屏幕的透明层。
- Tauri 能力配置允许提醒窗口调用确认与隐藏命令，并允许托盘、窗口隐藏和显示。

## 验收

- 在 Tauri 桌面版中关闭主窗口后，进程仍存活且托盘菜单可重新打开主窗口或退出。
- 到点时提醒窗置顶显示于主屏左上角，切换浏览器或其他应用后仍可见。
- 确认提醒后窗口隐藏；同时间多条待办依次显示；完成/编辑后的待办不重复提醒。
- Rust 单元测试覆盖时间解析、触发去重与队列；前端组件测试覆盖提醒内容、确认和隐藏命令。
- 网页提醒与桌面小组件回归不受影响。
