# 轻量设置中心设计

## 目标

将现有设置页改为类似 CCSwitch 的轻量配置中心。用户无需理解复杂接口参数，即可配置大模型、选择模型、测试连接和切换当前模型；同时补全外观、交互、提醒和数据设置。

## 信息架构

设置首页展示七张入口卡片：

1. 任务默认值
2. AI 与 API
3. 提醒方式
4. 外观与主题
5. 交互与快捷操作
6. 数据管理
7. 关于与诊断

每张卡片进入独立二级页。二级页保留“返回设置”，不进入一级导航。

## 功能真实性原则

每个设置必须有明确消费者、可观察效果和自动化测试。暂时没有任务字段、通知服务或操作入口支持的设置不显示。开关状态不能只保存在 localStorage。

## 任务默认值

默认优先级、状态、预计时长、AI 步骤范围、完成任务显示方式、排序、今日待办是否包含逾期、一周开始日和时间格式直接影响任务创建与列表查询。

## 关于与诊断

显示应用版本、数据版本、本机 API 状态、当前服务商/模型、通知权限、存储占用和最近 AI 错误。复制诊断信息时不得包含 API Key。

## AI 与 API

### 当前使用

页面顶部展示当前服务商、当前模型、启用状态和最近一次连接测试结果。新建任务的 AI 分析只使用这里标记为当前的配置。

### 系统服务商

OpenAI、DeepSeek、通义千问和智谱以卡片展示。点击卡片进入简化编辑：

- API Key
- 模型选择
- 测试连接
- 设为当前

系统服务商不可删除。Base URL 使用系统预设，只有展开“高级设置”后才能修改。

### 自定义服务商

“添加自定义 API”需要填写名称、API 地址、API Key 和模型。添加后与系统服务商一样显示为卡片，可编辑、测试、设为当前或删除。

API Key 继续保存在本机服务配置中，不写入浏览器 localStorage、页面响应、构建产物或 Git。

## 外观与主题

- 深色主题保持为默认主题。
- 强调色提供绿色、蓝色、橙色三个预设。
- 字体大小提供紧凑、标准、宽松三档。
- 界面密度控制卡片和页面间距。

## 交互与动效

- 页面切换动画开关。
- 减少动态效果开关。
- 删除任务前确认开关。
- 文本编辑提示开关。

## 提醒方式

- 浏览器通知授权与开关。
- 默认提前提醒时间。
- 提醒声音开关。
- AI 提醒开关。

## 数据管理

- 导出任务和本地偏好为 JSON。
- 从 JSON 备份导入。
- 清除任务数据。
- 恢复设置默认值。

清除操作必须二次确认；导入数据必须校验格式，失败时不得覆盖现有数据。

## 持久化

普通偏好保存在浏览器 localStorage。服务商元数据和 API Key 由本机服务保存，其中读取接口只返回服务商、模型、启用状态和 `hasApiKey`。

## 首轮边界

不实现用量统计、费用估算、MCP、Skills、会话管理、云同步和自动故障转移。设置中心仅服务当前任务管理与 AI 分析功能。

## 验证

- 五张设置卡都能进入独立页面并返回。
- 四个系统服务商可配置、测试并设为当前，但不可删除。
- 自定义服务商可添加、编辑、删除和设为当前。
- API Key 不出现在浏览器读取响应或 Git 中。
- 外观、交互和提醒偏好刷新后保留。
- 数据导入失败不会破坏现有任务。
