# 每天复用任务设计

## 交互

- 双击任务清单卡片的非交互空白区域，打开任务编辑窗口。
- 右击普通任务卡，显示“设置为每天复用任务”。
- 右击每天复用任务卡，显示“取消每天复用任务”。
- 点击页面其他位置、按 Escape 或选择菜单项后关闭右键菜单。

## 数据与状态

- `Task` 增加 `dailyReusable: boolean` 与 `lastResetDate?: string`。
- 每日复用任务显示“每日复用”标记。
- 应用加载及浏览器回到前台时，以本地日期检查复用任务。
- 当日期晚于 `lastResetDate` 时，将任务与所有步骤设为未完成，并写入当天日期。
- 取消复用不改变当前完成状态；旧任务默认不复用。
- 导入导出保持这两个字段并兼容旧备份。

## 验证

- 双击卡片可编辑，勾选、步骤气泡和右侧箭头点击不触发双击编辑。
- 右键菜单可以启用和取消每日复用。
- 日期变化只重置标记为每日复用的任务。
