# 任务详情页视觉重构设计

## 目标

把任务详情页优化为阅读优先的深色工作台，消除标题挤压、信息失衡、步骤横向溢出和空状态占位过大的问题，同时保留全部编辑与保存功能。

## 布局

- Header 分为三段：返回与任务身份、完成目标、独立进度卡。标题正常横向显示；修改标题和目标使用明确编辑控件，不让输入框承担展示职责。
- 桌面主体使用约 35%/65% 双栏；左栏为压缩的领域地图和资源摘要，右栏突出核心问题与执行步骤。
- 小于 840px 时切为单栏，底部操作条保持固定可见。

## 视觉层级

- 深色表面使用 `#0B0F14` 页面底、略亮的卡片底和克制边框；强调色仅用于状态、进度和主操作。
- 空状态显示为单行弱化提示，不再形成大量空白。
- 核心问题默认显示有限条目，并保留可展开入口。
- 步骤改为纵向卡片：勾选、序号、标题/问题、时长、操作各自占稳定区域；不允许横向滚动或文字压叠。

## 验收

- 长任务标题保持一行或自然换行，不出现逐字竖排。
- 1280px 宽度下步骤区无横向滚动，标题、时长和操作互不覆盖。
- 旧任务空数据状态紧凑、可读，不稀释执行区视觉权重。
- 深色和浅色主题都沿用已有主题变量。
