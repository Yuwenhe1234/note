# 智能任务备忘录 React UI 迁移设计

## 目标

将现有原生前端迁移为 Vite + React + TypeScript + Tailwind CSS，在保留五层 Agent 架构和现有任务数据的前提下，改进视觉效果、交互一致性与后续扩展能力。

## 产品层级

一级导航固定为：任务清单、今日待办、其他功能、设置。

聊天、AI 陪伴、放入桌面、今日消息、Agent 和未来扩展能力全部属于“其他功能”的二级页面，不进入一级导航。

## 技术方案

- 使用 Vite、React、TypeScript、Tailwind CSS、`lucide-react` 和 `gsap`，不引入其他 UI 库。
- 不照搬提示词中的视频逐帧捕获，避免高内存和移动端性能问题。
- 首版使用轻量动态背景；未来如使用视频，应采用短循环视频并提供静态降级。
- 保持原有本地存储键兼容，迁移不能导致已有任务丢失。

## 五层架构

- **L1 交互接入层**：改为 React 页面、组件和 Hooks，只处理输入、界面状态和展示。
- **L2 Agent 调度核心层**：迁移为 TypeScript 模块，继续负责意图路由、记忆和复合流程编排。
- **L3 能力插件层**：建立统一 `AgentPlugin` 接口；插件声明名称、版本、意图和执行函数。
- **L4 数据持久层**：保留数据范式、Repository 和本地存储；插件专属字段放入 `extendedFields`。
- **L5 基础能力层**：保留日志、事件、工具和存储能力，并预留模型、搜索、语音、解析和通知服务。

React 仅接管 L1，业务规则不得塞入组件。简单的纯界面行为不需要经过 Agent；任务创建、分析、提醒等业务行为必须经过 Agent 或明确的 Repository 接口。

## 目录建议

```text
src/
├─ app/                     # 应用入口、路由和全局装配
├─ L1-ui/
│  ├─ pages/                # 四个一级页面
│  ├─ features/             # 二级功能页面
│  ├─ components/           # 通用 UI 组件
│  └─ hooks/                # React 接入逻辑
├─ L2-agent/
├─ L3-plugins/
├─ L4-data/
├─ L5-services/
├─ styles/
└─ types/
```

## 视觉设计

- 整体采用黑色和近黑色沉浸背景。
- 顶部四项导航使用液态玻璃胶囊容器。
- 标题可使用 Instrument Serif；中文正文使用系统中文字体，Barlow 用于西文。
- 卡片采用半透明深色表面、细微高光边缘和克制阴影。
- 主操作使用高对比浅色按钮，次操作使用玻璃按钮。
- 页面进入使用淡入和小幅位移；卡片悬停仅轻微抬升和边缘高光。
- 背景视差限制为约 8–12px，并在触屏设备或“减少动态效果”下关闭。
- 状态变化必须提供文字或图形提示，不能只依赖颜色或装饰动画。

## 页面交互

### 任务清单

- 保留统计、搜索、筛选和任务列表。
- 新建任务采用“基础信息 → AI 分析结果确认”两阶段流程。
- AI 拆解的子任务允许逐项编辑，再由用户确认保存。
- 点击任务进入详情或编辑；完成任务后先展示反馈，再依据筛选条件决定是否隐藏。

### 今日待办

- 展示当天和逾期任务，支持手动创建与语音输入。
- 选中任务后可配置 AI 提醒；首版保存提醒配置并显示状态，真实系统通知留给 L5 后续实现。

### 其他功能

- 使用配置驱动的功能卡片展示聊天、AI 陪伴、放入桌面、今日消息、Agent 和拓展功能。
- 所有二级页面提供明确的返回路径。

### 聊天

- 提供历史会话、新建会话、关联任务、发送和停止生成的界面状态。
- 首版复用现有规则 Agent；未来大模型通过 L5 服务替换，不改变聊天组件接口。

### AI 陪伴与今日消息

- 首版完成高质量界面和本地可验证交互。
- 上传声音、内容抓取等外部能力未接入时明确标为“未配置”，不伪造成功结果。

### 设置

- 分为外观、交互、AI/API、提醒和数据区域。
- API 密钥不得完整回显，本地保存时显示安全提示。

## 数据流

```text
React 页面或组件
  → L1 Hook / 适配器
  → L2 Agent
  → L3 插件
  → L4 Repository 或 L5 服务
  → 标准结果
  → React 更新界面
```

## 错误与降级

- 旧数据读取失败时保留原存储并提示恢复，不静默覆盖。
- 插件失败返回统一错误结构，UI 展示可理解的错误信息。
- 字体或动态背景加载失败时使用系统字体和纯色背景。
- 动画不可用时不得影响导航、表单和任务操作。
- 外部 API 未配置时显示配置引导。

## 验证范围

- 四项一级导航和全部二级入口可达。
- 原有本地任务能读取、编辑并继续保存。
- 新建、分析确认、编辑、完成、删除、筛选和今日待办流程正常。
- 桌面端与移动端主要布局可用。
- 支持键盘焦点、Escape 关闭、表单标签和减少动态效果。
- TypeScript 类型检查、构建和核心模块测试通过。

## 首轮边界

首轮完成技术底座、四个一级页面、二级页面骨架、现有任务能力迁移和统一视觉系统。真实大模型、跨平台内容抓取、声音克隆、操作系统桌面组件和云同步不在首轮范围，但保留标准接口。
