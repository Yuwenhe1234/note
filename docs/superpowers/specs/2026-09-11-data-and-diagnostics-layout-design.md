# 数据管理与诊断页版式设计

## 目标

优化浅色主题下“数据管理”和“关于与诊断”的信息层级与操作可读性，避免默认文件控件、裸文本和不可见操作按钮。

## 数据管理

- 将导出、导入、清理已完成、清除全部和恢复默认设置呈现为独立操作行。
- 每行包含标题、简短说明和明确操作按钮；导入通过自定义文件选择按钮触发隐藏的文件输入。
- 不改变导入、导出、确认提示或清理逻辑；危险操作沿用警示语义色。

## 关于与诊断

- 将版本、数据版本、服务状态、模型、通知权限和存储大小排列为两列键值网格。
- 状态值使用浅色标签，复制动作使用可见的次级按钮。
- 不展示 API 密钥或其他敏感配置。

## 验收

- 两个页面与任务默认值共享圆角白卡、可读文字、细边框和间距。
- 浅色主题下没有浏览器原生文件输入外观或近白不可读按钮。
- 现有备份、恢复、清理和复制诊断功能不变。
