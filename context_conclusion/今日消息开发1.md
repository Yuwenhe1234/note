# 今日消息开发 1

## 已确定的产品规则

- “今日消息”位于网站“其他功能”内的二级页面，不打开浏览器新页或 Tauri 功能窗口。
- 用户添加具体 UP 主、账号、频道或网站来源；抖音/B站/小红书/YouTube 官网首页无账号信息，会被拒绝。
- 点击“刷新”时：首次每个来源展示最新 1 条；后续展示上次成功刷新后的全部新增内容。
- 每条消息展示真实视频/文章链接、标题、发布时间、封面、AI 摘要和重点；消息及缓存保留 3 天。

## 技术实现

- 动态平台通过 Playwright Core 使用项目专属 Edge 会话采集真实作品链接。
- 点击登录时仅打开一次可见 Edge；刷新时使用同一会话的后台无界面 Edge，不连续弹出网页。
- B站、YouTube、抖音、小红书适配器从动态页面提取作品链接或内嵌作品 ID；普通网站使用 HTML/Open Graph 解析。
- AI 总结复用项目“设置 → AI 与 API”的现有配置。

## 已验证

- 真实测试成功抓取 OpenAI YouTube 频道最新视频，返回具体 `watch?v=...` 链接、AI 摘要和重点。
- 全量测试：31 个测试文件、159 项测试通过；类型检查和生产构建通过。

## 注意事项

- 使用前需重新进入“今日消息”，旧的平台首页订阅会自动移除。
- 动态平台如要求登录或验证码，应先点击来源旁的登录按钮，在 Edge 完成操作后再刷新。
